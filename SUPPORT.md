# Support — legacy e-C3 Dashboard retired

> **This repository is deprecated and no longer maintained.**
> The former `e_c3_dashboard` integration v0.5.53 will not receive further fixes or updates.
> **SV Dashboard is a separate new HACS integration; it is NOT an automatic update.**

Use the maintained successor:

- [SV Dashboard repository](https://github.com/CaneTLOTW/sv_dashboard)
- [Installation and migration starting point](https://github.com/CaneTLOTW/sv_dashboard/blob/main/docs/INSTALLATION.en.md)
- [Latest stable release](https://github.com/CaneTLOTW/sv_dashboard/releases/latest)
- [SV Dashboard issues](https://github.com/CaneTLOTW/sv_dashboard/issues)
- [SV Dashboard discussions](https://github.com/CaneTLOTW/sv_dashboard/discussions)

Do not post new feature requests or troubleshooting reports against the legacy repository; it is kept only for reference. When reporting a defect in the successor, include the installed **SV Dashboard version** and redact VINs, credentials, GPS/location data, and raw Home Assistant `.storage` files.
