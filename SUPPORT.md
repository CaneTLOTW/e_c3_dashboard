# Support

For setup and usage questions, first review the
[installation guide](docs/INSTALLATION.en.md),
[entity catalog](docs/ENTITY_CATALOG.md), and
[capability matrix](docs/STELLANTIS_EC3_CAPABILITY_MATRIX.en.md).

Use GitHub Issues for reproducible bugs and well-defined, portable feature
proposals. Use [GitHub Discussions](https://github.com/CaneTLOTW/e_c3_dashboard/discussions)
for setup and usage questions, early ideas, compatibility observations, and
showing your dashboard. Use a private GitHub security advisory for
vulnerabilities or accidental exposure of private data.

See the [community guide](docs/COMMUNITY.en.md) for the expected information,
discussion categories, project scope, and privacy rules. Please do not post
VINs, credentials, exact locations, raw exports, or Home Assistant `.storage`
files in any public thread.
