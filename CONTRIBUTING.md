# Contributing — legacy project retired

**The original e-C3 Dashboard project is deprecated and unmaintained.** No new fixes, dependency updates, feature contributions or releases are planned here.

Please contribute to the successor: **[CaneTLOTW/sv_dashboard](https://github.com/CaneTLOTW/sv_dashboard)**.

- [New issues and bug reports](https://github.com/CaneTLOTW/sv_dashboard/issues)
- [New pull requests](https://github.com/CaneTLOTW/sv_dashboard/pulls)
- [Current installation instructions](https://github.com/CaneTLOTW/sv_dashboard/blob/main/docs/INSTALLATION.en.md)

**SV Dashboard must be installed separately in HACS.** It is not an update delivered to the legacy `e_c3_dashboard` integration.
