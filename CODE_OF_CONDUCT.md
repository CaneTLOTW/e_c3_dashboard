# Code of Conduct

Participants in this project are expected to be respectful, constructive and
mindful that vehicle and location data can be sensitive.

Harassment, personal attacks, publishing another person's private data, or
sharing credentials, VINs, location histories, and other sensitive information
without permission are not acceptable.

Report unacceptable behaviour privately through a GitHub security advisory or
by contacting the repository owner. Reports will be handled confidentially and
fairly. Maintainers may remove content or restrict participation when needed to
protect participants and the project.

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
